    How it works
    
    
    The task. Both probes estimate the same hidden phase φ. Each configuration is measured in two quadratures (X and Y), and the phase comes from atan2(⟨Y⟩, ⟨X⟩).
    
    
    Independent qubits. Each qubit starts in |+⟩ and picks up φ. N qubits give N independent samples per shot, so Δφ ≈ 1/√(N·shots).
    
    
    Entangled GHZ state. (|0…0⟩ + |1…1⟩)/√2 picks up Nφ. We un-entangle and read one qubit, so Δφ ≈ 1/(N·√shots).
    
    
    Noise. Every data qubit is coupled to its own environment qubit by a controlled-phase gate, and the environment is never measured. Each qubit keeps coherence c; the GHZ state keeps only cᴺ. The GHZ error grows like 1/(N·cᴺ), which is smallest at N ≈ −1/ln c.
    
    
    Uncertainty. Error bars come from binomial shot noise propagated through atan2 (the delta method). Dashed curves are the closed-form prediction.
    
    
    Backends. Every simulator on Qollab is free. IonQ backends accept one job per run, so the whole sweep is sent as a single job.
